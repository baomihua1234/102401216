# 失物有迹｜校园失物招领

本项目是一个可离线运行的校园失物招领网页，用于完成软件工程结对作业的程序实现部分。它实现了“发布 → 浏览/搜索 → 查看详情和联系 → 发布者更新状态”的完整闭环。

## 功能

- 发布寻物启事或招领信息，并校验必填项。
- 通过关键词、信息类型、物品类别和处理状态组合筛选。
- 查看物品详情并复制联系方式。
- 在“我的发布”中将待处理信息标记为“已解决”。
- 使用浏览器本地存储保留发布内容；可随时恢复示例数据。

## 如何运行

1. 下载或克隆本项目的全部文件，保持目录结构不变。
2. 用 Chrome 双击打开根目录的 `index.html`。
3. 不需要安装软件、启动服务器或联网。
4. 测试时，用 Chrome 打开 `tests/core.test.html`，页面会自动显示 12 个测试结果。

## 目录结构

```text
lost-found-web/
├─ index.html              # 页面入口
├─ css/style.css           # 页面样式与响应式布局
├─ js/core.js              # 可测试的校验、筛选、状态变更逻辑
├─ js/app.js               # 页面渲染、发布、详情、存储等交互
├─ tests/core.test.html    # 可离线打开的自动化单元测试
└─ README.md               # 使用说明
```

## 数据与隐私说明

数据只保存在当前浏览器的 LocalStorage 中；本演示没有服务器。联系方式只在详情弹窗展示。真实使用时应避免发布身份证号、完整学号等敏感信息，并在联系时核验物品细节。
